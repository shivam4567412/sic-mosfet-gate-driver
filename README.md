# Design and Characterization of a SiC MOSFET Gate Driver

## Overview
Four-week summer internship project at IIT Bhubaneswar
focused on the design, simulation and experimental
characterization of a SiC MOSFET gate driver system.

## Tools and Technologies
- Altium Designer
- LTspice
- Code Composer Studio
- TMS320F28379D C2000
- Yokogawa DLM3054 Oscilloscope

## Work Performed
1. Schematic design of isolated gate driver.
2. Two-layer PCB design and layout.
3. LTspice circuit simulation.
4. PWM generation and deadband implementation.
5. Hardware verification of gate driver.
6. Double Pulse Test and switching loss analysis.

## Experimental Results
Turn-on energy at 50 kHz: 57.09 uJ
Turn-off energy at 50 kHz: 79.87 uJ

## Key Learnings
- High-frequency PCB layout
- Gate driving of SiC MOSFETs
- ePWM configuration
- Switching transient analysis
- Parasitic ringing and switching losses
